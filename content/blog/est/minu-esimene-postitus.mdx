# Tervislik taldrik

Tere tulemast **DietlessAI esimese blogipostituse** juurde 🎉

Lihtne valem:

- 🥩 **Valgud** → kana, kala, tofu, oad
- 🍚 **Süsivesikud** → riis, kartul, kaerahelbed
- 🥗 **Köögiviljad** → pool taldrikust
- 🥑 **Rasvad** → avokaado, oliiviõli, pähklid

> Nipp: Tasakaal on kõige tähtsam.
